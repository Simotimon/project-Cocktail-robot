# D02 팀 차터 — 칵테일 바 로봇팔 팀

D02 · 팀 차터 · 작성 [이름](PM) · 검토 팀 전원 · 상태 검토 · v1.0

## 목표 한 줄

작은 칵테일 바의 칵테일 제조를 로봇팔이 맡아, 매번 같은 양으로 만들 수 있음을 MuJoCo 시뮬레이션으로 입증한다.

## 범위

| 구분 | 내용 |
|---|---|
| 한다(In) | 진열장에서 병 꺼내기·되돌려 놓기, 레시피 양만큼 따르기, 바 스푼으로 젓기, 셰이커 뚜껑 닫기·셰이킹·작은 캡 열기·거름망으로 따르기, 서빙 위치에 잔 내놓기, 반복 평가와 결과 기록 |
| 안 한다(Out) | 얼음 자동 공급, 가니시 장식, 액체 자체의 유체 시뮬레이션, 주문 받기·결제, 잔·셰이커 세척, 실물 로봇 |

레시피는 3개로 고정한다: 빌드 칵테일 2개(하이볼, 진토닉), 셰이크 칵테일 1개(다이키리).

## 플랫폼 결정

MuJoCo Menagerie의 UR5e 팔과 Robotiq 2F-85 그리퍼를 가져다 쓴다. 바 장면, 리니어 레일, 진열장, 병, 셰이커는 새로 만든다.

- 근거: 팔과 그리퍼는 이미 검증된 모델이다. UR5e는 리치 850mm, 들 수 있는 무게 5kg이라 가장 무거운 병(약 1.2kg)과 셰이킹을 감당한다.
- 위험: 셰이커 안 얼음 큐브의 충돌이 불안정할 수 있다 → 바 장면보다 셰이커 장면을 먼저 따로 만들어 확인한다.
- MuJoCo에는 액체 시뮬레이션이 없다 → 따른 양은 "기울기 각도 × 시간" 공식으로 계산한다.
